HUONG DAN DUA WEBSITE VNPT LEN VERCEL

Cach 1: Dua len Vercel bang GitHub
1. Giai nen file vnpt-vercel.zip.
2. Vao GitHub va tao repository moi.
3. Upload tat ca file trong thu muc vnpt-vercel len repository.
   Luu y: index.html phai nam o thu muc goc cua repository.
4. Vao https://vercel.com, dang nhap tai khoan.
5. Chon Add New > Project.
6. Chon repository vua tao tren GitHub, bam Import.
7. Phan cau hinh:
   - Framework Preset: Other
   - Build Command: de trong
   - Output Directory: .
8. Bam Deploy.
9. Sau khi xong, Vercel se cap link co dang https://ten-du-an.vercel.app

Cach 2: Dua len Vercel bang lenh
1. Cai Node.js neu may chua co.
2. Mo Terminal/CMD trong thu muc vnpt-vercel.
3. Chay lenh: npm i -g vercel
4. Chay lenh: vercel login
5. Chay lenh: vercel --prod

Ghi chu:
- File netlify.toml da duoc xoa vi chi dung cho Netlify.
- File vercel.json da duoc them de phu hop Vercel.
